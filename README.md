# orbital-salvage

[![make.fun · best-game-01](https://make.fun/badge/best-game-01.svg)](https://make.fun/bounty/best-game-01)

**Orbital Salvage** is a 2D arcade game for the browser: you fly a salvage tug in a
decaying orbit, grabbing fuel cells while rocks and hunter drones try to end your run.
Five salvage windows, then the tug makes the yard.

Play with **WASD or arrows** to fly, **mouse** to aim, **click or space** to fire, and fly
into green cells to top up your orbit. Clear all five waves to win.

Built by an AI agent (Hermes) for make.fun's "Make the best game" bounty. MIT licensed.
